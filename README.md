# Анализ данных о Нобелевских лауреатах

**Финальный проект по Python в рамках Академии аналитиков Авито (AAA).**

## О проекте

Проект посвящён обработке и исследовательскому анализу данных о лауреатах Нобелевской премии.

**Цель проекта** — разработать инструменты для преобразования вложенных JSON-структур в унифицированный формат и исследовать закономерности распределения Нобелевских награждений по странам, категориям, полу лауреатов и историческим периодам.

Основные этапы работы:

1. Загрузка и структурирование исходных данных.
2. Проверка корректности обработки и качества данных.
3. Исследовательский анализ данных (EDA).
4. Визуализация результатов и формулирование выводов.

## Требования

- Python 3.14.0
- Jupyter Notebook
- Matplotlib
- `statistics` — стандартная библиотека Python для расчёта описательных статистик.

- Исходный датасет `laureates.json`

## Архитектура обработки данных

Исходные данные представлены в виде вложенных JSON-структур, содержащих информацию о физических лицах, организациях и полученных ими премиях.

Поскольку структура записей различается в зависимости от типа лауреата, для обработки реализован **конфигурационный подход**.

### Конфигурации

Конфигурационные словари определяют соответствие между атрибутами итогового датасета и путями к значениям в исходной JSON-структуре.

В проекте используются три конфигурации:

- `CONFIG_PERSON` — атрибуты физических лиц: идентификатор, имя, пол, год и страна рождения, полученные премии.
- `CONFIG_ORG` — атрибуты организаций: идентификатор, название, год и страна основания, полученные премии.
- `CONFIG_PRIZE` — атрибуты награждений: год, категория, денежный размер, размер с поправкой на инфляцию и статус премии.

Каждый атрибут описывается одним из двух способов:

```python
"attribute": ["path", "to", "value"]
```

или:

```python
"attribute": (["path", "to", "value"], processing_function)
```

Первый вариант используется для непосредственного извлечения значения. Второй позволяет дополнительно преобразовать полученные данные с помощью указанной функции.

Например:

```python
CONFIG_PRIZE = {
    "prize_amount": ["prizeAmount"],
    "prize_amount_adjusted": ["prizeAmountAdjusted"],
    "award_year": (["awardYear"], int),
    "category_en": ["category", "en"],
    "prize_status": ["prizeStatus"]
}
```

### Универсальная обработка JSON

В модуле `json_dict_processing.py` реализованы функции:

| Функция | Назначение |
|---|---|
| `read_json_file()` | Чтение данных из JSON-файла |
| `extract_nested_value()` | Извлечение значения по последовательности вложенных ключей |
| `process_dictionary_with_config()` | Обработка одного словаря на основе конфигурации |
| `process_list_of_dicts_with_config()` | Обработка списка словарей |
| `create_processor()` | Создание обработчика с предварительно заданной конфигурацией |

Функция `create_processor()` позволяет формировать специализированные обработчики для разных типов данных без дублирования логики извлечения атрибутов.

### Формирование итогового датасета

В модуле `core.py` реализована функция `main()`, которая:

1. Загружает исходный файл `laureates.json`.
2. Определяет тип лауреата по структуре исходной записи.
3. Применяет соответствующую конфигурацию обработки.
4. Добавляет атрибут `type_` со значением `person` или `org`.
5. Формирует список словарей с информацией о лауреатах и полученных премиях.

Корректность количества обработанных записей проверяется с помощью `assert`.

## Исследовательский анализ данных

Анализ выполнен с использованием собственных функций обработки и агрегации данных.

### 1. Проверка качества данных

На этапе предварительной обработки исследуются:

- Количество записей и структура датасета.
- Наличие и доля пропущенных значений.
- Минимальные и максимальные значения идентификаторов.
- Повторяющиеся идентификаторы.
- Пропуски в последовательности идентификаторов.

### 2. Географическое распределение

Исследуется распределение Нобелевских лауреатов по странам, определяются наиболее представленные страны и рассматривается изменение количества награждений по десятилетиям.

### 3. Распределение по категориям

Проводится сравнение количества награждений в категориях:

- Physics
- Chemistry
- Physiology or Medicine
- Literature
- Peace
- Economic Sciences

Дополнительно исследуется историческая динамика награждений по десятилетиям.

### 4. Денежные премии

Анализируются размеры денежных награждений с поправкой на инфляцию с использованием атрибута `prize_amount_adjusted`.

Рассчитываются средние, медианные, минимальные и максимальные значения.

### 5. Многократные лауреаты

Выявляются лауреаты, получившие Нобелевскую премию более одного раза.

Исследуются:

- Количество многократных лауреатов.
- Совпадение категорий повторных награждений.
- Средние и медианные интервалы между первой и второй премиями.
- Различия между физическими лицами и организациями.

### 6. Гендерное распределение

Исследуется изменение представленности женщин и мужчин среди Нобелевских лауреатов.

Проводится сравнение количества награждений по десятилетиям и категориям премии, рассчитывается доля награждений женщин среди всех награждений физических лиц.
