# omd

Репозиторий содержит решения домашних заданий: hw1.py, hw2.py, hw3.py, hw4.py, hw5.py

## Установка зависимостей

Для работы необходим установленный Python 3.
Используются только стандартные библиотеки Python, установка дополнительных зависимостей не требуется.

## Запуск
**Клонируйте репозиторий:**
```bash
git clone https://github.com/Rseniia/omd.git
```
**Перейдите в директорию проекта:**
```bash
cd omd
```
**Переключитесь на ветку с домашними заданиями:**
```bash
git switch hw1
```
**Для запуска соответствующего домашнего задания выполните:**
```bash
python hw1.py
python hw2.py
python hw3.py
python hw4.py
python hw5.py
```

Каждое домашнее задание запускается отдельно. Для запуска задания достаточно выполнить соответствующую команду.
