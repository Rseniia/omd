## Решение домашнего задания по Функциям 

Реализованная программа, которая читает файл `Corp_Summary.csv` и формирует отчёт в зависимости от выбранного пользователем варианта.
На вход программы ожидается получить номер варианта отчета. 

## Требования

- Программа написана на **Python 3.14.0**
- Файл `Corp_Summary.csv` в одной папке с `task_function.py`

## Установка зависимостей

Дополнительные библиотеки устанавливать не требуется. Программа использует стандартный модуль Python csv.

## Запуск программы

**Клонируйте репозиторий:**
```bash
git clone https://github.com/Rseniia/omd.git
```

**Перейдите в директорию проекта:**
```bash
cd omd
```

**Переключитесь на ветку с домашними заданиями:**
```bash
git switch hw2
```
**Для запуска файла с домашним заданием выполните:**
```bash
python task_function.py
```

Введите интересующий вас номер варианта отчёта: 1, 2 или 3.

_**Варианты отчётов:**_ 

1. _Иерархия:_ для каждого департамента показано, какие команды в него входят.
2. _Сводка по департаментам:_ название, сколько человек, минимальная и максимальная зарплата, средняя по каждому департаменту.
3. _CSV-отчёт:_ сводка из второго варианта,
   сохранённая в файл `department_summary.csv`

## Результат

- Вывод отчётов 1 и 2 происходит в консоль
- Отчёт 3 сохраняется в CSV-файл с разделителем `;`

Файл `department_summary.csv` создаётся автоматически при выборе третьего варианта.
